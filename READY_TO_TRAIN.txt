⚡ QUICK TROUBLESHOOTING
===============================================================================

Error: "Failed to connect to Ollama"
  → Make sure: ollama serve is running in another terminal

Error: "Model llama3.1 not found"
  → Run: ollama pull llama3.1

Error: "LangChain not found"
  → Run: pip install langchain-community langchain

Error: "No module named 'torch'"
  → Run: pip install torch numpy pandas scikit-learn

Training slow?
  → Reduce epochs_per_step=3 in train_final_with_llm.py
  → Or use faster model: llm_model="mistral"

Memory error?
  → Reduce batch_size=16 in train_final_with_llm.py

adult.data not found?
  → Script auto-generates synthetic data, no action needed
