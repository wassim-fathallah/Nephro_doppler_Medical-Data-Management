# 📊 Training with Metrics Collection & Plotting

## Quick Start

### 1. Run Training (100 iterations)
```bash
cd c:\Users\MSI\Desktop\MEMOIRE
python train_final_with_llm.py
```

The training will:
- Run for exactly **100 iterations**
- Save metrics after each iteration
- Continue even after both targets (80% accuracy + 80% p-rule) are reached
- Save all data to `training_metrics.json`

**Duration**: ~1-2 hours on CPU (depending on dataset size)

### 2. Plot Results
After training completes, create the plot:
```bash
python plot_training_results.py
```

This generates:
- **File**: `training_progress.png` (saved automatically)
- **Display**: Interactive plot with:
  - X-axis: Iteration number (1-100)
  - Y-axis: Metric value (0.0-1.0)
  - Blue line: Accuracy
  - Red line: P-rule (fairness)
  - Green dashed line: Target (0.80)

3. **Save to JSON**: All metrics written to `training_metrics.json`

## Troubleshooting

### "training_metrics.json not found"
- Make sure training completed successfully
- Check console output for any errors
- Re-run training: `python train_final_with_llm.py`

### Plot doesn't show
- Install matplotlib if needed: `pip install matplotlib`
- Check that training_metrics.json exists
- Run again: `python plot_training_results.py`

### Want to customize the plot?
Edit `plot_training_results.py` and change:
- Colors: `'b-o'` and `'r-s'` parameters
- Markers: `'o'` (circle) and `'s'` (square)
- Figure size: `figsize=(12, 6)`
- DPI: `dpi=300`
- Title or labels
